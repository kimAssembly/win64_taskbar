# LaptopBar — 노트북용 C# 상단바 프로토타입

## v0.3.2

상단바 폭은 모델/시스템/오른쪽 패널의 실제 DesiredSize를 합산하여 계산합니다. 오른쪽에 고정 여백을 추가했으며 AI 8가지 조합 × GPU 유무에 대해 설정 버튼이 최소 18 DIP 안쪽에 있는지 검증합니다. 상단바의 ToolTip 속성 및 실행 중 추가하던 말풍선을 제거했습니다. 설정/프롬프트 내부 안내는 유지합니다.

## v0.3.1

AI 버튼을 누르면 설정 패널이 닫힙니다. 버튼의 보라색 배경은 실제 AI/설정/연결 창이 열려 있을 때만 표시하며 닫으면 기본 배경으로 돌아갑니다. 회색/보라색 작은 점은 로컬 연결 상태 표시로 별도 관리합니다.

GPU는 Windows PDH의 GPU Engine Utilization Percentage를 읽습니다. 프로세스별 사용률을 같은 어댑터·엔진별로 더한 뒤 가장 바쁜 엔진을 표시합니다. 엔진들의 사용률을 모두 더한 값이 아닙니다. 유효한 지표가 없으면 GPU 표시와 공간을 접습니다. 0%는 정상 측정값이므로 계속 표시됩니다. CPU/RAM과 동일하게 약 3초마다 갱신합니다.

## v0.3

설정의 AI 표시 체크박스로 Qwen/Oss/GPT 버튼을 개별 표시합니다. 모두 해제할 수도 있으며 빈 공간은 줄어듭니다. 미사용 시 자동 숨기기는 기본 OFF, 대기 시간은 기본 8초(3~60초 조절)입니다. 바에 마우스가 있거나 이 앱의 팝업이 열려 있으면 카운트다운을 미룹니다. 숨겨지면 주 화면 상단의 작은 표시 영역에 마우스를 대어 다시 펼칩니다. 설정을 끄면 즉시 복원합니다. 트레이 더블클릭으로 수동 숨기기를 했다면 트레이로 복원해야 합니다.

Qwen 및 Oss 프롬프트 제목 옆에 각각 Qwen / OpenAI 식별 로고를 벡터로 포함합니다. 로고 출처와 라이선스는 THIRD-PARTY-NOTICES.txt를 참고하세요. 기존 startup 등록 경로와 settings.json은 유지합니다.

## v0.2 변경

최신 수정: 프롬프트/설정의 큰 장식 문구를 제거했습니다. GPT 버튼은 Windows AppsFolder에서 ChatGPT 앱 실행 ID를 찾아 네이티브 앱 활성화 API로 실행합니다. 현재 기기의 실행 ID는 OpenAI.Codex_2p2nqsd0c76g0!App입니다. 수동 EXE 지정이 있으면 우선 사용하며, 설치된 앱을 못 찾을 때만 웹을 엽니다.

Windows 시작 시 실행 스위치는 현재 사용자 HKCU/Software/Microsoft/Windows/CurrentVersion/Run의 LaptopBar 값에 실행 파일 경로를 등록/해제합니다. 작업 관리자 시작 앱에서도 관리할 수 있습니다. 모델은 자동 로드하지 않습니다. 실행 폴더를 옮겼다면 새 위치에서 스위치를 다시 켜세요. 실제 로그인 시 동작은 다음 로그인에서 확인할 수 있습니다.

- 메인 바, 프롬프트, 연결, 설정 패널을 보라색 테마로 통일했습니다.
- 작은 Qwen / Oss 버튼으로 로컬 모델 프로필을 선택합니다. 연결 확인 전/닫힌 상태는 회색, 서버가 해당 모델을 제공하면 보라색 점을 표시합니다. 열린 프롬프트는 12초마다 서버와 모델 목록을 확인합니다.
- 각 프로필은 모델 목록에서 이름에 qwen / oss가 포함된 모델을 우선 선택합니다. 다른 프로필로 바꾸면 대화창을 닫고 새 프로필을 엽니다. 실제 모델 로드/언로드는 실행기에서 관리합니다.
- GPT는 외부 ChatGPT 바로가기입니다. 설정에서 실제 앱 EXE를 지정하면 앱을 열고, 미지정이면 chatgpt.com을 엽니다. 앱 로그인 세션을 읽거나 답변을 가져오지는 않습니다. API 키/과금은 사용하지 않습니다.
- 모든 팝업은 점 → 가로 확장 → 전체 창의 약 380ms 애니메이션으로 나타납니다. 설정에서 끌 수 있습니다.
- 점 세 개 버튼이 별도 설정 패널을 엽니다. 항상 위, 애니메이션, 위치 초기화, GPT 앱 지정, 숨기기/종료를 제공합니다.
- 보라색 L 트레이 아이콘: 더블클릭으로 표시/숨기기, 오른쪽 클릭으로 메뉴. 아이콘이 숨겨진 영역에 배치되는지는 Windows가 관리하며 사용자가 직접 드래그할 수 있습니다. 앱을 종료하면 아이콘도 사라집니다.
- 프로필 서버 주소, GPT 경로, 애니메이션 설정은 실행 파일 옆 settings.json에 저장됩니다. 대화는 저장하지 않습니다.

Windows x64 / .NET 9 Desktop Runtime. WPF + XAML로 제작. 외부 NuGet 패키지와 WebView가 없습니다.

## 실행

`bin/Release/net9.0-windows/LaptopBar.exe`를 더블클릭하세요. .exe만 이동하지 말고 같은 폴더의 DLL/runtimeconfig 파일을 함께 유지하세요.

- 상단 중앙에 64 DIP 높이의 작은 바가 나타납니다. 배경을 드래그하면 이동합니다.
- CPU 전체 사용률, 시스템 RAM 사용량, 배터리/충전 여부, 날짜/시간을 실제 Windows API로 읽습니다. 3초마다 갱신합니다.
- `···`에서 항상 위, 위치 초기화, 숨기기, 종료를 선택합니다.
- Wi-Fi/Bluetooth/스피커 아이콘을 누르면 보라색 빠른 연결 팝업이 열립니다. Wi-Fi는 실제 무선 어댑터 연결 여부와 어댑터 이름을 표시합니다(SSID/인터넷 접속 보장은 아님). Bluetooth는 Windows의 classic Bluetooth 라디오와 캐시된 연결 기기를 표시하며 BLE 전용 기기는 누락될 수 있습니다. 타일을 누르면 Windows 설정으로 이동합니다.
- 기본 스피커/마이크의 실제 볼륨과 음소거 상태를 Core Audio API로 읽습니다. 슬라이더와 아이콘 클릭은 실제 시스템 볼륨/음소거를 변경합니다. 마이크를 녹음하지 않습니다. 기본 장치가 바뀌면 4초 이내 다시 읽습니다.
- 숨긴 바는 시스템 트레이 아이콘을 더블클릭하여 복원합니다. 트레이 오른쪽 메뉴에서도 종료할 수 있습니다.
- Windows 작업표시줄은 유지되며 상단바용 화면 공간은 예약하지 않습니다. 최대화된 창 위에 겹칠 수 있습니다.
- 주 모니터 기준으로 위치를 계산하며 화면 크기/배율 변경에 대응합니다. 좁은 화면에서는 CPU/RAM 영역을 접습니다.

## 로컬 AI

`LOCAL AI` 클릭 → 주소 입력 → `연결` → 모델 선택 → 채팅. `Ctrl+Enter` 전송, `중지`로 취소합니다.

| 실행기 | API 주소 |
|---|---|
| LM Studio | http://127.0.0.1:1234/v1 |
| llama.cpp | http://127.0.0.1:8080/v1 |
| Ollama | http://127.0.0.1:11434/v1 |

실행기에서 모델과 API 서버를 먼저 실행해야 합니다. 모델 다운로드/자동 시작/종료, IDE 파일 편집, 도구 실행, 자동 타일링은 이 버전에 포함되지 않습니다. gpt-oss reasoning 내용은 표시하지 않고 최종 content만 표시합니다. 모델 전환은 실행기에서 하세요.

통신은 같은 컴퓨터의 HTTP loopback만 허용하고 프록시 및 리다이렉트는 사용하지 않습니다. 대화는 메모리에만 보관하며 창을 닫으면 사라집니다. 최근 6회 대화만 유지하지만 입력 텍스트가 매우 길면 모델 컨텍스트 제한을 넘을 수 있습니다. 서버 내부의 추론 취소/모델 언로드 여부는 각 실행기 설정에 달려 있습니다.

## 개발

Visual Studio 2022의 .NET 데스크톱 개발 워크로드와 .NET 9 SDK로 `LaptopBar.csproj`를 열거나:

```powershell
dotnet build LaptopBar.csproj -c Release
```

`MainWindow.xaml`: 바 디자인 / `MainWindow.xaml.cs`: 창·트레이 / `SystemMetrics.cs`: 실제 시스템 지표 / `AiWindow.xaml`과 `.cs`: AI 팝업 및 스트리밍 API.

`LaptopBar.exe --smoke-test`는 실제 지표와 WPF 렌더링 결과를 실행 폴더의 `verification`에 저장하고 종료합니다.

GPU 점유율은 정확한 Intel 엔진별 집계가 필요해 아직 포함하지 않았습니다. API 서버 미실행 상태는 OFFLINE으로 표시합니다. 모델이 없을 때 가짜 답변을 만들지 않습니다. 관리자 권한, 자동 시작 등록 및 시스템 설정 변경이 필요하지 않습니다.
